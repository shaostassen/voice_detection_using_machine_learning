SpeechLens

Local language identification and robust transcription. Point it at audio, get back the language with a calibrated-ish probability, a transcript with per-segment confidence, and an honest set of warnings — computed entirely on your own hardware, with no cloud calls.

Context

Whisper is easy to call and hard to trust. Left at library defaults it hallucinates fluent text over silence and music, loops on itself, and reports none of it — the output looks identical whether the model heard a sentence or a fan. For anything unattended, a confident wrong transcript is worse than no transcript.

The interesting engineering is therefore not the model. It is the harness around it: deciding what is speech before decoding, deciding what language it is without trusting a single window, and marking low-quality output instead of silently passing it along.

Approach

  • VAD gating first. Silero (ONNX, CPU) segments speech before the decoder ever runs — the single largest anti-hallucination measure, since the most reliable way to stop the model inventing words over noise is to not hand it the noise. An energy-VAD fallback keeps the path alive if the ONNX assets are unavailable.
  • Chunk-voted language ID. Rather than trusting one window, several chunks each vote, and the distributions fuse as a log-space geometric mean. The property that buys: two clean windows can veto one corrupted window, because a near-zero probability anywhere drags the fused score down multiplicatively rather than being averaged away. Each vote costs an encoder pass only — the lazy segment generator is deliberately never consumed.
  • An explicit decode contract. Every robustness knob lives in one RobustnessConfig dataclass instead of scattered call sites, so the decode behavior is inspectable, diffable, and testable rather than a pile of implicit library defaults.
  • Confidence that surfaces. Per-segment confidence is exp(avg_logprob) — the geometric mean token probability — and anything under the threshold is flagged in the output schema, the CLI, and the web UI. The design goal is that flags rise before the transcript goes bad, which is the property the SNR sweep is built to falsify.

Context carry-over is off by design. It is the setting that makes Whisper read fluently and the setting that lets one hallucinated segment condition the next into agreeing with it. Error propagation is the worse failure. These defaults are load-bearing: changing one requires an A/B on the SNR sweep, recorded in the validation log.

Result

  • 30offline tests
  • 0weights to run them
  • —RTF · large-v3 · T4
  • —WER at −5 dB SNR

The suite runs in seconds with no network and no model weights, on every push, across Python 3.11 and 3.12. That is a deliberate architectural property, not a convenience: the pipeline takes its transcriber and detector by injection, so the orchestration logic is testable without three gigabytes of parameters. Anything that genuinely needs weights lives in a separate validation harness and never in the test suite.

Three interfaces sit on the one pipeline — a Python API, a CLI, and a FastAPI service with a single-page web UI — and the whole thing holds a hard dependency ceiling: no torch.

The two pending chips stay em dashes until a measured run fills them in. Every number this project publishes carries the hardware, model, compute_type, and date that produced it; authoritative figures come from a cloud T4 running large-v3 at float16, since no development machine here has an NVIDIA GPU. An unsourced number is a bug.
